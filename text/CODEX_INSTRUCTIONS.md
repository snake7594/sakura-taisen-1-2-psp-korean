# 작업 지시서 — 사쿠라대전 1&2 (PSP) 한글화 번역

이 문서 하나만 읽고 바로 시작할 수 있게 썼습니다. 작업 루트는 `D:\psp\사쿠라대전1_2` 입니다.

---

## 1. 할 일

`text/` 안의 TSV에서 **`ko` 열만** 채웁니다. 일본어 → 한국어 게임 번역입니다.

| 파일 | 행 수 | 내용 |
|---|---:|---|
| `text/sakura1_adv.tsv` | 31,481 | 사쿠라대전 1 — 어드벤처(일상·대화) |
| `text/sakura1_slg.tsv` | 3,586 | 사쿠라대전 1 — 전투 |
| `text/sakura2_adv.tsv` | 38,822 | 사쿠라대전 2 — **본편 대사** (분량의 절반) |
| `text/sakura2_evt.tsv` | 12,773 | 사쿠라대전 2 — 이벤트·전투·시스템 |

전체 86,662행 / 1,778,948자. `flags` 열에 `dup=<key>` 가 있는 행은 **건드리지 말고
비워 두세요.** 앞에서 나온 문장과 완전히 같고, 마지막에 스크립트가 자동으로 채웁니다.
그래서 실제 번역 대상은 **45,421행 / 1,043,741자** 입니다.

**순서**: 파일을 위에서 아래로 순서대로. 행 순서가 곧 대화 순서라서, 앞뒤 행이 화자와
상황을 알려주는 유일한 단서입니다. 무작위로 하면 존댓말/반말과 화자 판단이 틀어집니다.

## 2. 절대 규칙 (형식)

어기면 게임에 넣을 수 없습니다. 매 청크마다 검증 스크립트를 돌리세요.

1. **`ko` 열만 수정.** `key` `file` `index` `id` `flags` `ja` 는 한 글자도 바꾸지 마세요.
2. **열은 7개, 탭 구분.** 셀 안에 진짜 탭이나 진짜 줄바꿈을 넣지 마세요.
3. **줄바꿈은 `\n` 두 글자.** 원문의 줄 수를 넘기지 마세요. 최대 3줄입니다.
4. **한 줄 길이는 게임마다 다릅니다.**

   | 파일 | 한 줄 | 줄 수 |
   |---|---:|---:|
   | `sakura1_adv`, `sakura1_slg` | **21자** | 3줄 |
   | `sakura2_adv`, `sakura2_evt` | **14자** | 3줄 |

   실기(PPSSPP)에서 자를 넣어 잰 값입니다. 한글·한자·전각기호·**띄어쓰기 모두 1자**,
   반각 영문·숫자는 0.5자. 자간은 문자에 관계없이 고정이라 띄어쓰기도 한 칸을 온전히
   먹습니다.

   **사쿠라 2는 특히 주의.** 상한을 넘기면 게임이 자동으로 줄을 바꾸는데, 그 과정에서
   **15번째 글자가 사라집니다.** 반드시 직접 `\n` 으로 끊으세요.

5. **`<XXXX>` `{XXXX}` 토큰은 그대로, 같은 순서로.** → 3절 참고.
6. **한글은 KS X 1001 완성형 2350자 안에서만.** 폰트 슬롯 제한입니다. 일반적인
   한국어는 자동으로 만족하고, `뷁` `쀍` 같은 음절만 피하면 됩니다.
7. 파일 인코딩은 **UTF-8 BOM** 유지.

## 3. 제어 토큰 — `sakura2_adv.tsv` 에 1,591개

`<FFFA>` 처럼 꺾쇠에 든 16진수는 게임 제어 코드입니다. 지우거나 옮기면 연출이 깨집니다.
사쿠라 1 쪽에는 없고 사쿠라 2 본편에만 있습니다(38종).

- `<FFFC><000X>` 는 보통 문장 **맨 앞**, `<FFFA><00XX>` 와 `<FFFD>` 는 **맨 뒤**에 옵니다.
  그 자리를 그대로 지키세요.
- `<FFFA>` `<FFFB>` `<FFFC>` 뒤에 붙는 `<00XX>` 는 **딸린 인자**입니다. 두 개를 한 덩어리로
  다루고 사이에 글자를 끼워 넣지 마세요.
- `{XXXX}` 는 정체를 모르는 외자입니다. 그대로 두세요.

```
원문  <FFFC><0005>帝都に暗躍する悪漢たちに、\n敢然と立ち向かう赤い影。<FFFA><0076>
번역  <FFFC><0005>제도에 암약하는 악한들에게\n당당히 맞서는 붉은 그림자.<FFFA><0076>
```

## 4. 반각 숫자가 들어간 71행 — 게임 데이터입니다

`sakura1_adv.tsv` 70행과 `sakura1_slg.tsv` 1행은 대사가 아니라 **선택지 데이터**입니다.
반각 숫자는 게임이 읽는 ID라서 건드리면 로직이 깨집니다. **일본어 부분만** 번역하세요.

```
원문  0\n20002\nすみれと行く
번역  0\n20002\n스미레와 간다          ← 숫자 두 줄은 그대로
```

`S1S:m16mes:76` 의 `.n.nN.nN.nN.nN.nn` 같은 문자열은 립싱크 데이터입니다. 그대로 두세요.

번역문에 반각 영문·숫자를 **새로 쓰지 마세요.** 폰트에 반각 글리프가 없어 화면에
안 나옵니다. 숫자가 필요하면 전각(`１２３`)을 쓰세요.

## 5. 외자(gaiji) — 반드시 그대로

폰트가 해당 Shift-JIS 자리에 표준 문자가 아닌 전용 글리프를 그립니다. `ja` 열에는
실제로 화면에 보이는 문자를 넣었고 `flags` 에 `gaiji=XXXX` 로 표시했습니다.
모양은 `text/gaiji_legend.png` 를 보세요.

| 코드 | 표시 | 사쿠라 1 | 사쿠라 2 | 근거 |
|---|---|---:|---:|---|
| `81AC` | `⁉` | 973행 | 897행 | 「〜んですか⁉」 |
| `81B8` | `‼` | 1,765행 | 1,073행 | 「帝国華撃団参上‼」 |
| `81BF` | `翔` | — | 39행 | 「翔鯨丸」 |
| `81DC` | `冑` | — | 63행 | 「霊子甲冑」 |
| `81E5` | `璧` | — | 12행 | 「完璧」 |

`⁉` 와 `‼` 는 전용 글리프라서 일반 `!?` `!!` 로 바꾸면 **글자가 깨집니다.**
반드시 원문 그대로 복사하세요.

## 6. 번역 방침

**작품**: 1996·1998년 세가 게임. 가상의 「태정(太正)」 시대 — 다이쇼 로망 분위기의
제도(도쿄)에서 극단 단원인 소녀들이 증기기관 로봇을 타고 싸우는 연애 시뮬레이션입니다.

- **구어체 대사.** 문어체·번역투 금지. 실제로 사람이 말하는 문장으로.
- **간결하게.** 화면이 좁습니다. 길어지면 뜻을 유지한 채 줄이세요.
- **존댓말/반말을 화자와 상대에 맞게.** 주인공은 상관에게 존댓말, 대원에게는 부드러운 반말.
- **말줄임표 `……` 유지.** `...` 로 바꾸지 마세요.
- **`！？` 는 한국어 관례대로 `!` `?` 로.** 단 외자 `⁉` `‼` 는 그대로(5절).
- 원문에 없는 정보를 넣거나 있는 정보를 빼지 마세요.
- **모르면 비워 두고 목록으로 보고하세요.** 추측 번역 금지.

## 8. 작업 절차

1. 한 번에 **200행 내외**씩. 앞뒤 문맥을 함께 읽고 화자를 판단하세요.
2. 저장할 때마다 검증:
   ```bash
   python tools/check_translation.py text/sakura2_adv.tsv
   ```
   `문제 없음 ✔` 이 나올 때까지 고칩니다. 오류는 행 `key` 로 표시됩니다.
3. 네 파일을 끝낸 뒤 중복 행을 채웁니다:
   ```bash
   python tools/propagate_dups.py text/sakura1_adv.tsv text/sakura1_slg.tsv text/sakura2_adv.tsv text/sakura2_evt.tsv
   ```
   (원본은 `.bak` 로 자동 백업)
4. 전부 다시 검증합니다.

검증기가 보는 것: 열 개수 / 원문 변조 / 제어코드 손실 / 줄 수 / 줄 길이 /
완성형 밖 한글 / 진행률. 마지막에 **고유 한글 글자 수**가 나오는데
**2350을 넘으면 폰트에 다 넣을 수 없으니** 보고하세요.

## 9. 예시

```
key                ja                                        ko
S2A:SK0101:1       きのうの嵐がウソのようだな。\n              어제 폭풍이 거짓말 같군.\n
                   どうやら桜も散らずに\nすんだみてえだ。       벚꽃도 지지 않고\n넘어간 모양이다.
S2:EV00001:2       帝国華撃団参上‼                            제국화격단, 등장‼
S1A:0801tbl:576    0\n20002\nすみれと行く                     0\n20002\n스미레와 간다
```

사쿠라 2 예시는 각 줄이 14자 이내입니다. `‼` 를 그대로 둔 점, 선택지 행의 숫자를
건드리지 않은 점을 보세요.
